# DOMO 제품 방향 (v5)

## 교수님 질문: 여러 페르소나가 한 질문에 답하는 것이 더 효과적인가

결론부터 말하면, 모든 질문에서 그렇지는 않습니다.

멀티 에이전트 토론이 사실성과 추론을 높인다는 연구가 있습니다(Du et al., 2023, Improving Factuality and Reasoning in Language Models through Multiagent Debate). 하지만 같은 비용으로 비교하면 모델 하나가 여러 번 답하고 다수결로 고르는 방식(self-consistency)을 잘 이기지 못한다는 결과도 있습니다(Smit et al., 2024, Should we be going MAD?). 모델이 스스로 고치는 과정이 오히려 정답을 틀리게 바꾸는 경우도 보고됐습니다(Huang et al., 2024, Large Language Models Cannot Self-Correct Reasoning Yet). 페르소나끼리 대화를 보면서 답하면 서로에게 맞장구치는 동조 문제도 생깁니다.

단, 팀이 분명히 유리한 순간은 있습니다.

| 팀이 유리한 순간 | 이유 | DOMO 서비스 |
|---|---|---|
| 서로를 보지 않고 따로 만들 때 | 아이디어가 한쪽으로 쏠리지 않고 다양해진다 | 컨셉 3안 |
| 다른 회사 모델이 검증할 때 | 같은 모델은 같은 실수를 반복하지만, Claude와 Codex는 틀리는 지점이 다르다 | 데스크리서치, 사실 검증 |
| 정해진 기준표로 채점할 때 | 시점을 나누면 한 사람이 놓치는 약점이 드러난다 | 크리틱 리허설 |

그래서 저는 기본은 AI 1명이 빠르게 답하고, 위 세 가지 순간에만 팀을 부르는 구조로 바꾸려 합니다. 마지막 결정은 언제나 사용자가 합니다.

## 주장을 데이터로 확인하는 장치: 블라인드 비교

논문 결과가 디자인 과제에도 그대로 맞는지는 아직 모릅니다. 그래서 앱 안에 블라인드 비교(`/비교`)를 넣었습니다. 같은 요청을 AI 1명 답과 팀 답으로 받아 순서를 섞어 보여주고, 사용자가 누가 썼는지 모르는 상태에서 더 나은 답을 고릅니다. 결과는 과제 유형(크리틱, 컨셉, 리서치, 글쓰기, 일반)별로 쌓이고, 인사이트 화면에서 팀 승률과 평균 시간·비용을 볼 수 있습니다.

| 확인할 가설 | 기준 |
|---|---|
| 크리틱·컨셉·리서치에서는 팀이 낫다 | 해당 유형에서 팀 승률 60% 이상 |
| 일반 질문·글쓰기에서는 1명으로 충분하다 | 해당 유형에서 팀 승률 50% 이하 |
| 팀의 추가 비용은 감당할 만하다 | 팀 답의 시간·비용이 1명 답의 3배 이내 |

수업 시범 운영 동안 이 데이터를 모아, 교수님 질문에 실측으로 답하려 합니다.

## 누가 쓰는가: 디자인 전공 대학생

주 타겟은 디자인 전공 3~4학년입니다. 이 사람들은 매주 크리틱을 받고, 한 학기에 여러 프로젝트를 동시에 진행하며, 판넬과 발표 자료를 직접 만듭니다. 하지만 일반 AI 채팅은 과제 맥락과 본인 기준을 기억하지 못해서, 매번 처음부터 설명해야 합니다.

| 니즈 | 지금의 불편 | DOMO가 주는 것 |
|---|---|---|
| 크리틱 전에 약점을 미리 알고 싶다 | 친구나 선배에게 물어도 시점이 하나뿐이다 | 크리틱 리허설: 교수·사용자·디테일 시점 점수표, 고칠 점 Top 3, 예상 질문 |
| 컨셉이 막혔다 | AI에게 물으면 비슷한 안만 나온다 | 컨셉 3안: 내 1차 가설에서 출발해 확장·반박·와일드카드 |
| 리서치에 출처가 필요하다 | AI가 없는 통계를 지어낸다 | 데스크리서치: 측정·파생·미확인 라벨과 출처, Codex 교차 검증 |
| 마감이 겹친다 | 일정이 머릿속에만 있다 | 대화에서 나온 과제를 기억 탭에 자동 등록, 예약 작업 |

## 가격보다 서비스

DOMO는 각자 이미 쓰고 있는 Claude와 Codex 구독을 그대로 씁니다. 그래서 사용자에게 따로 받는 요금은 없습니다. 차별점은 가격이 아니라 위 네 가지 서비스와, 쓸수록 내 기준을 배우는 기억에 있습니다.

## 다른 사람이 쓰는 방법

코드는 GitHub 저장소로 공개하고, 각자 자기 Codespace나 Mac에서 DOMO를 띄웁니다. 첫 화면에서 계정을 만들고, 같은 환경의 터미널에서 본인 Claude·Codex 계정으로 로그인하면 바로 쓸 수 있습니다. 로그인 정보는 DOMO가 아니라 공식 CLI가 각자의 컴퓨터 안에서만 관리합니다.

제 Mac 서버 한 곳에 여러 사람이 각자 구독으로 로그인하는 방식은 쓰지 않습니다. Anthropic은 승인 없이 제3자 서비스가 claude.ai 로그인을 제공하는 것을 허용하지 않기 때문입니다. 정식 공개 전에는 약관을 다시 확인하려 합니다.
