# DOMO

**디자인 전공생을 위한 AI 스튜디오.** 평소에는 AI 한 명이 빠르게 답합니다. 크리틱 리허설, 컨셉 3안, 데스크리서치, 사실 검증처럼 팀이 정말 나은 순간에만 Claude와 Codex로 꾸린 팀이 서로를 보지 않고 일한 뒤 합칩니다. 정말 나은지는 앱 안의 블라인드 비교로 직접 확인할 수 있습니다. 왜 이렇게 설계했는지는 [docs/PRODUCT.md](docs/PRODUCT.md)에 정리했습니다.

## 시작하기

**앱으로 설치 (권장)**: [다운로드 페이지](https://juwangoh.github.io/domo/#start)에서 Windows용 `.exe` 또는 Mac용 `.dmg`를 받아 엽니다. 앱 안에서 "연결하기" 버튼을 누르면 Claude·Codex 설치와 로그인까지 이어서 진행됩니다. 터미널은 필요 없습니다.

- 본인 Claude·ChatGPT 구독으로 로그인해서 씁니다. DOMO는 AI 계정 정보를 보관하지 않습니다.
- 서명하지 않은 무료 배포라 처음 열 때 확인 창이 한 번 뜹니다. 넘기는 방법은 다운로드 페이지에 있습니다.
- 대화와 기억은 앱 데이터 폴더에, 첨부와 대화기록은 `문서/DOMO`에 저장됩니다.
- 창을 닫아도 트레이(메뉴 막대)에 남아 폰 접속과 예약 작업이 계속됩니다. 종료와 "컴퓨터를 켤 때 자동으로 실행"은 트레이 메뉴에 있습니다.

**터미널로 직접 실행 (개발용, Node 20 이상)**
```bash
git clone https://github.com/juwangoh/domo.git && cd domo
npm start                # http://localhost:3939 → 회원가입 → "연결하기" 버튼
```
GitHub Codespaces에서는 버튼 대신 터미널에서 `claude auth login`, `codex login`을 실행합니다. 다른 기기(폰 등)에서 처음 가입할 때는 서버 터미널에 찍힌 6자리 설정 코드가 필요합니다.

```bash
npm run demo   # 요금 없는 체험용 mock AI (http://localhost:3940)
npm test       # 자동 테스트 (mock, 요금 없음)
npm install && npm run app    # 데스크톱 앱을 개발 모드로 실행
npm run dist                  # 내 컴퓨터용 설치 파일 만들기 (dist/)
```

**배포**: `v1.0.0` 같은 버전 태그를 푸시하면 GitHub Actions가 Mac·Windows 설치 파일을 만들어 Releases에 올리고, 다운로드 페이지의 버튼이 최신 버전을 가리킵니다.

## 쓰는 법

- **새 채팅**: 기본 AI 한 명과 대화합니다. 입력창의 AI 칩을 누르면 대화할 AI와 모델을 바꿀 수 있습니다.
- **팀 서비스**: 입력창의 "팀 서비스" 버튼을 누르거나 명령을 입력합니다.
  - `/크리틱` 작업물을 첨부하고 `기준:` 아래에 교수님 기준표를 적으면, 교수·사용자·디테일 시점이 따로 채점한 뒤 점수표, 고칠 점 Top 3, 예상 질문을 줍니다.
  - `/컨셉` 내 1차 가설에서 출발해 서로 다른 방향 3안을 만들고, 내 기준으로 채점한 결정 카드를 줍니다.
  - `/리서치` 출처와 라벨이 붙은 팩트시트를 만들고, Codex가 교차 검증합니다.
  - `/검증` 직전 AI 답을 Codex가 한 번 더 확인합니다.
  - `/비교` 같은 요청을 AI 1명과 팀이 따로 답합니다. 누가 썼는지 모르게 보고 고르면 인사이트에 쌓입니다.
- **과제·기억**: 대화에서 나온 과제, 프로젝트, 내 정보, 내 기준이 자동으로 쌓이고, 모든 AI가 같은 기억을 씁니다.
- **AI 팀**: 페르소나(SOUL), 성격, 역할, 모델, 권한, 플러그인을 편집합니다.

## 폰에서 쓰기

- **항상 켜두기 (권장)**: `npm run service -- install` 한 번이면 백그라운드 서비스로 등록됩니다. 터미널을 닫거나 맥을 재시동해도 자동으로 켜지고, 서버가 죽으면 다시 켜집니다. 해제는 `npm run service -- uninstall`, 상태는 `npm run service`, 재시작은 `npm run service -- restart`. 로그는 `data/server.log`.
- **같은 Wi‑Fi**: 서버 실행 시 출력되는 `http://192.168.x.x:3939` 주소를 폰 브라우저로 여세요.
- **홈 화면 앱처럼**: 사파리 공유 버튼 → "홈 화면에 추가".
- **밖에서 (LTE 등) — 고정 주소**: 이 Mac에 [Tailscale](https://tailscale.com/download/mac)을 설치하고 로그인하면, 설정 탭 → "외부에서 접속 허용"이 **Tailscale Funnel**로 `https://<맥이름>.<tailnet>.ts.net` 주소를 엽니다. 이 주소는 **바뀌지 않고**, 서버·맥을 재시작해도 유지됩니다. 폰에는 Tailscale 앱이 필요 없습니다. 처음 한 번은 설정 탭에 뜨는 "Funnel 허용하기" 링크에서 허용을 눌러야 합니다.
- Tailscale이 없으면 `https://…trycloudflare.com` 임시 주소로 대체됩니다(서버를 다시 켜면 바뀜).
- 서버가 도는 동안은 맥이 유휴 잠자기에 들지 않습니다. 단, 덮개를 닫으면 잠들어서 동작하지 않습니다.

## 스튜디오 모드 (v3)

일반 Claude와 다른 점은 **내 판단이 들어가는 자리**가 정해져 있다는 것입니다. 기억에 저장된 "사고 주권 프로토콜"을 그대로 따릅니다.

1. **분류 (PM)**: 실행형(조사·수정)은 컨펌 없이 바로 끝냅니다. 학습형은 설명한 뒤 재진술을 요청합니다. 사고형(컨셉·방향·디자인)만 아래 흐름으로 갑니다.
2. **브리프 → 컨펌 A**: PM이 목표·완료 기준과 질문을 씁니다. **내 1차 가설**을 먼저 묻고, "패스"하면 팀에 맡깁니다.
3. **발산**: 리서처(팩트시트: 측정·파생·미확인 라벨 + 출처)와 컨셉터(내 가설 확장 / 반박 / 와일드카드 3안)가 **서로의 결과를 보지 않고 동시에** 작업합니다.
4. **크리틱 → 컨펌 B**: 크리틱이 **내 기준**으로 3안을 채점하고, 검증이 사실 리스크를 봅니다. PM이 결정 카드(얻는 것/잃는 것, 팀 추천, 이견)를 올리면 **내가 고릅니다**.
5. **시안 → 컨펌 C**: 프로듀서(유일한 제작자)가 내 스킬(ux-figma-slides, juwang-writing-style, deck-minimal-editorial)로 시안을 만들고, 크리틱·검증이 봅니다. 컨펌하거나 고칠 점을 적으면 같은 세션에서 고칩니다.
6. **확정 → 프로젝트 보고**: 결정 기록과 남은 일(기억 탭 과제로 등록).

- **내 기준 (기억 탭 첫 칸)**: 모든 AI가 가장 먼저 읽는 디렉터의 판단 기준입니다. 컨펌 B·C에서 내가 고르거나 돌려보낸 **이유**에서 자동으로 배우고, 직접 고칠 수 있습니다.
- **역할**: 프로필 → "스튜디오 역할"로 정합니다(이름과 무관). 각 SOUL은 맡는 것 / 하지 않는 것 / 원칙 / 쓰는 스킬로 경계를 나눴습니다.
- **명령**: `/바로`는 컨펌 없이 끝까지, `/스튜디오`는 분류 없이 사고형으로, `/중단`은 진행 중인 프로젝트를 닫습니다. 프로젝트 보드의 "닫기"도 같습니다.
- **모델**: 프로듀서만 Opus 5.5, 나머지는 Sonnet 5, 검증은 Codex(low)를 씁니다. 발산·크리틱 단계는 대화 전체가 아니라 지시서와 필요한 산출물만 받습니다.
- 설계 근거: MetaGPT(역할별 산출물 형식), Anthropic 멀티 에이전트 리서치(명확한 지시서 + 독립 병렬), Google AI co-scientist(생성 → 채점), LangGraph interrupt(멈췄다 재개), Midjourney 개인화(선택에서 취향 학습), 멀티 에이전트 토론의 동조 문제(합의 강요 대신 독립 생성 + 결정은 사람).
- 기존 데이터 전환: `node scripts/migrate-studio.js` (서버를 멈추고 실행, `data/*.backup-studio.json`에 자동 백업).

## v4 — 화면

- **브랜드**: 라이트는 크림 종이 위의 먹색, 다크는 먹색 위의 크림. 포인트 색은 테라코타 하나("내 차례", 링크).
- **실시간 진행**: AI가 지금 하는 일("웹 검색 · …", "피그마 · …", "파일 읽는 중 · …")과 쓰고 있는 글이 실시간으로 보입니다 (Claude `stream-json`, Codex `--json` 이벤트).
- **결정 카드**: 컨펌 B에서 A/B/C가 카드로 나란히 나오고, 크리틱의 "내 기준" 점수와 팀 추천이 표시됩니다. 카드를 고르고 이유를 한 줄 적으면, 그 이유가 "내 기준"으로 학습됩니다.
- **답장·복사**: AI 말풍선을 탭하면 답장·복사 버튼이 나옵니다. 답장하면 AI는 어느 발언에 대한 말인지 함께 받습니다.
- **첨부**: 입력창 왼쪽 ＋ 또는 붙여넣기로 이미지·PDF·텍스트를 보냅니다. `workspace/첨부/`에 저장되고, Claude는 경로를 Read로 열고 Codex는 `-i`로 받습니다.
- **내 차례 알림**: 설정 → 알림. 스튜디오 컨펌 대기·완료 보고·오류·1:1 답장 때 폰으로 웹 푸시가 옵니다(VAPID + aes128gcm, 외부 라이브러리 없음). 아이폰은 홈 화면에 추가한 DOMO 앱에서만 켤 수 있습니다.

## v2 기능 한눈에

- **회의 모드** (AI 회의실): 안건을 보내면 의장 AI가 회의를 엽니다. 참석 AI들이 돌아가며 토론하고, 끝나면 회의록과 할 일이 **기억 → 과제**에 자동 등록됩니다. 다른 방에서도 `/회의 안건`으로 이번 메시지만 회의로 진행할 수 있습니다.
- **새 페르소나**: 프로필 탭 → "새 페르소나 만들기" → 템플릿(비서실장·디자인 크리틱·리서처·반대론자·아이디어 뱅크·기획자) 선택 → "참여할 단톡방" 체크 → 만들기. 대화방 안에서는 오른쪽 위 👤+ 버튼으로 바로 만들어 초대하거나 기존 AI를 초대·내보낼 수 있고, 참여·퇴장은 대화방에 알림으로 남습니다.
- **프로필 탭**: 내 이름·사진·소개, AI 프로필 추가·편집을 합니다. 편집 항목은 사진, 이모지, 색, 역할, **페르소나(SOUL)**, 성격 프리셋, 엔진, 모델, 권한, 플러그인입니다.
- **모델 변경**: 대화 중 AI 아바타를 탭하거나, 대화방 정보에서 모델 버튼을 누르면 바로 바뀝니다.
- **기억 탭**: 과제, 프로젝트, 내 정보, 기억 노트를 봅니다. 대화가 끝나면 자동으로 쌓이고, 직접 편집할 수도 있습니다. "Hermes 가져오기"를 누르면 `~/.hermes/memories`를 가져옵니다.
- **설정 탭**: 외부 접속(LTE), 자동 기억, 예약 작업(cron), 플러그인(MCP), 비밀번호 변경을 합니다.
- 과거 대화 원문은 `workspace/대화기록/`에 쌓여서 AI가 검색할 수 있습니다.

## 사용법

- **AI 단톡방**: 클로드가 답하고 코덱스가 검토합니다. 통과하거나 최대 라운드에 도달하면 자동으로 멈춥니다.
- **@이름**: `@코덱스 이거 맞아?` 처럼 쓰면 그 AI만 한 번 답합니다 (입력창 아래 버튼으로도 가능).
- **중단**: 진행 중 상단 오른쪽 빨간 ■ 버튼을 누르면 실행 중인 AI 프로세스를 바로 종료합니다.
- **말풍선 탭**: AI 답변의 응답 시간과 비용(Claude)을 볼 수 있습니다.
- **대화방 이름 탭 → 정보**: 라운드 수 조절, AI 기억 초기화, 대화방 삭제.
- 진행 중에 보낸 메시지는 다음 차례의 AI가 이어서 읽습니다.

## 설정 — `agents.json`

| 항목 | 설명 |
|---|---|
| `name`, `emoji`, `color`, `persona` | 이름·아바타·성격. 영상처럼 "마리코", "설인" 등으로 바꿔도 됩니다. |
| `engine` | `claude` / `codex` / `mock` |
| `model` | 비워두면 CLI 기본값. 비용을 줄이려면 클로드에 `"sonnet"` 등 지정 |
| `allowedTools` / `disallowedTools` | 클로드 권한. 기본은 **읽기·검색만** 허용, 파일 수정·명령 실행은 금지 |
| `sandbox` | 코덱스 권한. 기본 `read-only` |
| `defaultRooms` | 첫 실행 시 만들어지는 대화방 (첫 번째 멤버가 작업, 나머지가 감사) |

AI는 `workspace/` 폴더를 작업 폴더로 사용합니다. 대화 기록과 세션은 `data/`에 저장되며 서버를 재시작해도 유지됩니다.

## 구조

```
server.js            진입점 (포트, LAN 주소 출력)
src/engines.js       claude -p / codex exec 호출, 세션 resume, 중단 시 프로세스 그룹 종료
src/studio.js        스튜디오 단계별 지시서·컨펌 정의
src/orchestrator.js  스튜디오·작업·회의·검토 진행, 작업→감사→수정 루프, 판정 파싱, @멘션, 세션 복구
src/store.js         대화방·메시지·AI 세션 저장 (JSON, 원자적 쓰기)
src/auth.js          비밀번호(scrypt) + 로그인 쿠키
src/app.js           HTTP API + 실시간 이벤트(SSE)
src/push.js          웹 푸시 (VAPID 서명 · aes128gcm 암호화)
src/uploads.js       첨부 파일 저장·제공
src/tunnel.js        외부 접속 (Tailscale Funnel 고정 주소 / Cloudflare 임시 주소)
scripts/service.js   macOS 백그라운드 서비스(launchd) 등록
public/              아이메시지 스타일 UI (PWA)
test/                성공 기준 자동 테스트
```

성공 기준은 [SUCCESS_CRITERIA.md](SUCCESS_CRITERIA.md) 참고.
